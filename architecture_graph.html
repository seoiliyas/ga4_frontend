Chat Streaming Flow (SSE) — GTM Mode

sequenceDiagram
            participant U as User (Browser)
            participant D as Dashboard.tsx
            participant C as chatApi.ts
            participant R as routes/chat.ts
            participant S as gemini-chat.ts
            participant DB as D1 / Postgres
            participant KV as KV / GCS
            participant G as Vertex AI Gemini

            U->>D: Types question / attaches files + clicks Send
            D->>D: Append user msg + empty model placeholder
            D->>C: sendMessageStream(sessionId, question, signal)
            C->>R: POST /api/chat {sessionId, question, chatMode: "gtm", model, attachmentIds}

            R->>DB: Verify session ownership + load history + loadAttachments()
            R->>KV: get("container", cacheTtl: 3600)
            R->>S: streamGtmChat(...)
            S->>KV: Check cache key (model + sha256(container))

            alt Cache exists & valid
                KV-->>S: Return cache name
            else Cache miss / expired
                S->>G: caches.create(model, containerJson, ttl: 3600s)
                G-->>S: Return cache name
                S->>KV: put(cacheKey, cacheName, expirationTtl: 3600)
            end

            S->>G: generateContentStream(history + question + fileParts)

            loop SSE chunks
                G-->>S: text chunk
                S-->>C: data: {"text":"..."}
                C-->>D: onChunk(text)
                D->>D: Append chunk to model msg
            end

            S-->>C: data: [DONE]
            S->>DB: INSERT user + model messages + link attachments
            S->>DB: UPDATE session.updated_at

            D->>C: renameSession(title) on first reply
            C->>R: PATCH /api/sessions/:id

GA4 Parallel Function Calling & Private Charting Flow

sequenceDiagram
            participant U as User (Browser)
            participant D as Dashboard.tsx
            participant C as chatApi.ts
            participant R as routes/chat.ts
            participant S as gemini-chat.ts
            participant G as Vertex AI Gemini
            participant GA4 as GA4 Data/Admin APIs
            participant QC as QuickChart v4
            participant Store as R2 / GCS + DB

            U->>D: Types GA4 question + clicks Send
            D->>C: sendMessageStream(sessionId, question, "ga4")
            C->>R: POST /api/chat {sessionId, question, chatMode: "ga4"}

            R->>Store: Verify session + ga4_property_id + load history
            R->>S: runGA4Chat(...)
            S->>Store: Decrypt + refresh GA4 OAuth access token

            loop Up to 20 tool turns (parallel Promise.all per turn)
                S->>G: generateContent() with 8 function declarations
                G-->>S: functionCalls[]
                par GA4 API tool calls
                    S->>GA4: Execute GA4 Data / Admin REST call
                    GA4-->>S: JSON metrics / dimensions
                and Chart tool calls
                    S->>QC: POST /chart (version 4, PNG)
                    QC-->>S: PNG binary bytes
                    S->>Store: Save PNG to CHAT_FILES + attachments -> /api/files/:id
                end
                S->>G: Return functionResponses[]
            end

            G-->>S: Final candidate (thought parts filtered out)
            S-->>R: {answer, charts}
            R->>Store: INSERT user + model messages (with charts JSON)
            R-->>C: JSON {answer, charts}
            C-->>D: Render Markdown + fetch charts via AuthImage

Authentication & Signed GA4 OAuth Flow

sequenceDiagram
            participant U as User
            participant AP as AuthPage / Dashboard
            participant AC as AuthContext / chatApi
            participant W as API (Worker / Cloud Run)
            participant DB as D1 / Postgres
            participant G as Google OAuth 2.0

            Note over U,DB: --- Bootstrap / Atomic Invite Signup / Login ---
            U->>AP: Submits credentials (+ INV-key for signup)
            AP->>AC: bootstrap / signup / login
            AC->>W: POST /api/auth/... (rate limited)
            W->>DB: PBKDF2 hash/verify + atomic invite claim
            W-->>AC: {token, user} (30-day Bearer token)

            Note over U,G: --- HMAC-Signed GA4 OAuth Popup ---
            U->>AP: Clicks Connect GA4 Account
            AP->>AC: getGa4OAuthUrl() (Bearer Header)
            AC->>W: GET /api/ga4/oauth/authorize?format=json
            W->>W: signState({userId, ts, nonce, origin}, TOKEN_ENCRYPTION_KEY)
            W-->>AC: {url: accounts.google.com/...}
            AP->>G: Open popup to Google consent (analytics.readonly + userinfo.email)
            G-->>W: GET /api/ga4/oauth/callback?code=...&state=...
            W->>W: verifyState() + 10m TTL check
            W->>G: Exchange code for tokens + userinfo email
            W->>DB: Encrypt tokens (AES-GCM) -> UPSERT ga4_oauth_tokens
            W-->>AP: HTML-escaped result page -> postMessage(origin)
